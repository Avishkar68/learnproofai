---

### Architecture Overview

- **Frontend**: React 19, Vite, Tailwind CSS, Framer Motion, Lucide Icons, Capacitor mobile integration.
- **Backend API**: Node.js, Express, Socket.io, Redis, Prisma ORM.
- **Microservices & Infrastructure**: LiveKit WebRTC, Matrix Conduit homeserver, PostgreSQL, Redis Cache, Nginx Reverse Proxy.
